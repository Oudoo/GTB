# Implementation decisions and deviations

Recorded per the decision-change procedure in document 09. Each entry names the original requirement,
what was chosen, why, the security/financial effect and how it is verified. Entries marked
**Deviation** depart from a documented default; the others are choices the plan left open.

## Corrections to earlier entries

- **DEC-002** said that `compose.yaml` "is still delivered". It was not in the repository until commit `33dbba9`. It is now, and it has still **not been executed** (no Docker daemon in the implementation environment).
- **DEC-002 / document 11:** `pnpm db:local` with `POSTGRES_ADMIN_URL` (the path used with Docker and in CI) did not work until commit `848e538`: a `-d` argument after the connection URL made `psql` drop the host and password. The first CI run found it. Both paths were then executed locally (see the review file).
- `package.json` named `pnpm smoke` and `pnpm worker:status` from the first commit, but the two script files did not exist until commit `33dbba9`.
